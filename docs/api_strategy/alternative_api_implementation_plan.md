## 🚀 実装戦略

### Phase 1: Twelve Data実装 (最優先)
**理由**: 無料APIキー、高制限、包括的銘柄対応

**実装範囲**:
- CoinGecko 22欠損銘柄の完全代替
- Alpha Vantage株式データの補完
- 統合データクライアントへの組み込み

**APIキー要件**: 
- ✅ **無料登録のみ** - ユーザーがAPIキー取得必要
- 登録URL: https://twelvedata.com/

### Phase 2: Binance API実装 (仮想通貨特化)
**理由**: 仮想通貨データの最高品質・最高制限

**実装範囲**:
- BTC, ETH, USDT, USDC等主要仮想通貨
- リアルタイム価格データ
- 取引量・詳細データ

**APIキー要件**:
- ⚠️ **Binanceアカウント作成必要** - ユーザーが取引所登録

### Phase 3: Coinbase API実装 (バックアップ)
**理由**: アメリカ系仮想通貨データの信頼性

**実装範囲**:
- Binance APIの代替・バックアップ
- 規制対応が必要な地域での利用

**APIキー要件**:
- ⚠️ **Coinbaseアカウント作成必要** - ユーザーが取引所登録

## 🛡️ リスク管理

### 実装リスク
1. **論文再現破損リスク**: 各API実装後に必ず検証実行
2. **データ互換性リスク**: データ形式の統一化必須
3. **レート制限リスク**: 複数APIの適切な負荷分散

### 銘柄選定相談事項

**現在の問題**:
- 37 CoinGecko銘柄中22銘柄が未取得
- BTC/ETH等基本的な仮想通貨も欠損

**提案**:
1. **主要仮想通貨優先**: BTC, ETH, USDT, USDC等
2. **市場規模基準**: 時価総額Top20の確実な取得
3. **分析価値基準**: LPPL分析に適した価格変動パターン

**相談ポイント**:
- 37銘柄全て必要か、主要銘柄に絞るか
- 新しい有望銘柄の追加検討
- 地域・セクター分散の考慮
