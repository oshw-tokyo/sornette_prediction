# Sornetteモデル分析サービス 法的コンプライアンスガイド

## 1. エグゼクティブサマリー

本ガイドは、Sornetteモデルによる市場分析をサブスクリプション型サービスとして提供する際に、金融商品取引法の投資助言業規制を回避し、合法的に事業を運営するための包括的な指針です。

### 推奨アプローチ
**「データ分析プラットフォーム型」**として、以下の3層防御により違法性リスクを最小化：
1. **技術的防御**：ユーザーによる追加分析を必須とする設計
2. **法的防御**：研究・教育目的の実質化と明示
3. **運用的防御**：適切な免責事項とサポート体制

## 2. 法的リスクの構造分析

### 2.1 投資助言業に該当する要件
| 要件 | 内容 | リスク要因 |
|------|------|-----------|
| **特定性** | 特定の金融商品への投資判断提供 | 個別銘柄のスコアリング |
| **対価性** | 報酬を得る | サブスクリプション料金 |
| **営業性** | 反復継続 | 定期的なデータ更新 |
| **助言性** | 投資判断の根拠となる情報提供 | クラッシュ予測という性質 |

### 2.2 規制リスクレベル評価
- **高リスク（回避必須）**：予測結果を「買い/売りシグナル」として提供
- **中リスク（要対策）**：クラッシュ時期の直接的な予測提示
- **低リスク（許容可能）**：数理モデルの計算結果をデータとして提供

## 3. 違法性回避の具体的手段

### 3.1 サービス設計による回避策

#### A. データレイヤーの明確な分離
```
[生データ] → [数理モデル処理] → [数値結果] → [可視化]
                                          ↓
                                    [ユーザー分析]
                                          ↓
                                    [投資判断]
```

**実装要件**：
- 提供するのは「数値結果」まで
- 「投資判断」への変換はユーザー側で実施
- 分析ツールは提供するが、結論は出さない

#### B. ユーザー分析機能の必須化
```python
# 推奨実装例
class AnalysisPlatform:
    def provide_data(self):
        return {
            "sornette_metrics": {...},  # 数値のみ
            "market_data": {...},        # 生データ
            "statistics": {...}          # 統計値
        }
    
    def user_tools(self):
        # ユーザーが自由に使える分析機能
        return {
            "clustering": self.clustering_tools,
            "custom_indicators": self.indicator_builder,
            "backtesting": self.backtest_engine
        }
    
    # 以下は実装しない
    # def investment_recommendation(self): ❌
    # def buy_sell_signal(self): ❌
```

### 3.2 研究・教育目的の実質化

#### A. コンテンツ構成
| 要素 | 割合 | 内容例 |
|------|------|--------|
| **教育コンテンツ** | 30% | Sornetteモデルの理論解説、実装方法 |
| **研究ツール** | 40% | パラメータ調整、モデル検証機能 |
| **データ提供** | 30% | 計算結果の可視化、データダウンロード |

#### B. 学術的体裁の維持
- 論文引用の明記
- 数式・アルゴリズムの公開
- 限界と前提条件の明示
- 研究コミュニティ機能

### 3.3 利用規約・免責事項の設計

#### 必須記載事項
```markdown
【重要事項説明】
1. 本サービスは金融商品取引法に基づく投資助言・代理業ではありません
2. 提供情報は学術的な数理モデルの計算結果であり、投資推奨ではありません
3. 投資判断は必ずお客様ご自身の責任で行ってください
4. 本サービスの情報により生じた損失について一切責任を負いません

【利用制限】
- 本サービスの出力を直接的な投資判断の根拠とすることを禁じます
- 第三者への投資助言に本サービスを利用することを禁じます
- 自動売買システムへの直接接続を禁じます（APIの場合）
```

### 3.4 マーケティング・広告の規制

#### 使用可能な表現
✅ 許可される表現：
- 「市場の数理的分析ツール」
- 「Sornetteモデルの研究プラットフォーム」
- 「金融データの可視化サービス」
- 「独自分析のための基礎データ提供」

#### 使用禁止表現
❌ 避けるべき表現：
- 「クラッシュを予測」
- 「投資タイミングを提示」
- 「AIが最適な売買を判断」
- 「勝率○%の実績」

## 5. 段階的事業展開プラン

### Phase 1: プロトタイプ（1-3ヶ月）
- **対象**: 研究者・学術関係者10名限定
- **形態**: クローズドベータ
- **目的**: モデルの妥当性検証とUI/UX改善
- **リスク**: 極小（研究目的が明確）

### Phase 2: 限定公開（4-6ヶ月）
- **対象**: 法人顧客のみ（B2B）
- **価格**: 月額10-30万円
- **規模**: 20-30社
- **リスク**: 小（法人向けは規制が緩い）

### Phase 3: 一般公開（7-12ヶ月）
- **対象**: 個人投資家含む
- **価格**: 月額2-10万円
- **規模**: 100ユーザーまで
- **リスク**: 中（適切な対策により管理可能）

### Phase 4: スケール判断（1年後）
年商1,000万円超えた時点で：
- オプション1: 投資助言業登録を取得
- オプション2: 海外法人化
- オプション3: 現状維持（リスク許容）

## 6. リスクシナリオと対応策

### シナリオ別対応計画

| シナリオ | 発生確率 | 影響度 | 対応策 |
|---------|---------|--------|--------|
| 金融庁からの照会 | 20% | 中 | 事業モデル説明資料で対応 |
| ユーザーからの投資損失クレーム | 40% | 小 | 免責事項＋返金対応 |
| 競合からの通報 | 10% | 中 | 弁護士対応＋是正 |
| メディアでの批判的報道 | 5% | 大 | PR戦略＋サービス改善 |
