# 複数ウィンドウ（期間）フィッティングの詳細説明

## 概要

複数ウィンドウフィッティングは、FCO（Financial Crisis Observatory）が採用する重要な手法で、異なる時間スケールでの市場動向を同時に分析することで、より信頼性の高いクラッシュ予測を実現します。

---

## 1. なぜ複数ウィンドウが必要か？

### 1.1 単一ウィンドウの問題点

単一期間（例：365日）のみでフィッティングする場合：
- **過学習リスク**: 特定期間のノイズに過度に適合
- **時間スケールの見落とし**: 短期・中期・長期のパターンを見逃す
- **信頼性の欠如**: 単一の結果では統計的信頼性が低い

### 1.2 複数ウィンドウの利点

```
短期窓（125-250日）: 直近の急激な変化を捉える
中期窓（250-500日）: 中期的なトレンドを把握
長期窓（500-750日）: 長期的なバブル形成を検出
```

---

## 2. FCO方式の複数ウィンドウフィッティング

### 2.1 具体的なプロセス

**ステップ1: 時間窓の生成**
```python
# 126個の異なる時間窓を生成
windows = []
for window_size in range(750, 124, -5):  # 750日から125日まで5日刻み
    windows.append(window_size)
# 結果: [750, 745, 740, ..., 130, 125] = 126個の窓
```

**ステップ2: 各窓でのフィッティング**
```python
現在時点（t=1000）から遡って、各窓サイズでデータを切り出し：

窓1: t[250:1000] (過去750日分)
窓2: t[255:1000] (過去745日分)
窓3: t[260:1000] (過去740日分)
...
窓126: t[875:1000] (過去125日分)
```

**重要**: すべての窓は**同じ終点（現在）**を共有し、**開始点のみが異なる**

### 2.2 図解

```
時間軸 →
[===============================] 750日窓（長期）
 [==============================] 745日窓
  [=============================] 740日窓
                ...
          [====================] 250日窓（中期）
                ...
                   [===========] 125日窓（短期）
                              ↑
                           現在時点（共通の終点）
```

## 3. よくある誤解と正しい理解

### 3.1 誤解：「異なるタイミングで順にフィッティング」

❌ **間違った理解**：
「月曜日に365日窓、火曜日に300日窓、水曜日に250日窓...と順番に分析」

✅ **正しい理解**：
「**同一時点**で、126個の異なる期間を**同時に**分析」

### 3.2 なぜこれが「ほぼ同じデータ」ではないのか？

**理由1: LPPLモデルの非線形性**
- LPPLは非線形モデルのため、データ期間が5日違うだけでもパラメータが大きく変化
- 特に臨界時間（tc）の推定値が敏感に反応

**理由2: 異なる市場フェーズの捕捉**
```
750日窓: バブル形成の初期段階から現在まで全体を見る
500日窓: バブル成長期から現在を重点的に見る
250日窓: バブル成熟期から現在を詳細に見る
125日窓: 直近の加速段階のみに焦点
```

**理由3: 統計的ロバスト性**
- 126個の独立したフィッティング結果の統計分布を分析
- 外れ値の影響を軽減し、中央値や最頻値で信頼性を評価

## 4. DS-LPPLS Confidenceの計算

### 4.1 フィルタリング条件

各窓でのフィッティング結果を以下の条件でフィルタリング：

| 条件 | 閾値 | 意味 |
|------|------|------|
| Damping | ≥ 1.0 | 発散しない安定な解 |
| m | 0.1 < m < 0.9 | 理論的に妥当な範囲 |
| ω | 2 < ω < 25 | 現実的な振動周波数 |
| tc | > 現在時刻 | 未来の予測 |

### 4.2 信頼度の算出

```
DS-LPPLS Confidence = 条件を満たすフィット数 / 126

例：
- 126窓中50窓が条件を満たす → Confidence = 39.6%
- 126窓中100窓が条件を満たす → Confidence = 79.4%
```

## 5. 実装例（概念的）

```python
def multi_window_analysis(prices, current_date):
    """複数ウィンドウでのLPPL分析"""
    
    results = []
    
    # 126個の時間窓で分析
    for window_size in range(750, 124, -5):
        # 現在から遡ってwindow_size分のデータを取得
        window_data = prices[-window_size:]
        
        # LPPLフィッティング
        fit_result = lppl_fit(window_data)
        
        # 結果を保存
        results.append({
            'window_size': window_size,
            'tc': fit_result.tc,
            'm': fit_result.m,
            'omega': fit_result.omega,
            'damping': fit_result.damping,
            'r_squared': fit_result.r_squared
        })
    
    # フィルタリング条件を適用
    valid_results = filter_results(results)
    
    # Confidence計算
    confidence = len(valid_results) / 126
    
    # tc予測のクラスタリング（中央値など）
    tc_predictions = [r['tc'] for r in valid_results]
    final_tc = np.median(tc_predictions)
    
    return {
        'confidence': confidence,
        'predicted_crash_date': final_tc,
        'all_results': results
    }
```

## 6. 実際の効果

### 6.1 1987年ブラックマンデーの例

FCOの研究によると：
- **長期窓（750日）**: 1987年8月頃を予測
- **中期窓（400日）**: 1987年9月頃を予測
- **短期窓（200日）**: 1987年10月頃を予測（正解）

→ 複数窓の結果を統合することで、10月19日のクラッシュを高精度で予測

### 6.2 信頼性の向上

単一窓での予測精度: 約60%
複数窓での予測精度: 約85%（FCO報告）

---

## 7. まとめ

複数ウィンドウフィッティングは：

1. **同一時点で異なる期間を同時分析**（順次ではない）
2. **各期間が異なる市場フェーズを捉える**
3. **統計的信頼性を大幅に向上**
4. **DS-LPPLS Confidenceという定量的指標を提供**

これにより、単一期間分析では不可能な、高信頼性のクラッシュ予測が実現されます。
